# Contributing to Glyph Mobile

First off, thank you for considering contributing to Glyph Mobile! It's people like you that make Glyph such a great tool for the developer, sysadmin, and DevOps community.

## Where do I go from here?

If you've noticed a bug or have a feature request, make sure to check our [GitHub Issues](https://github.com/TheLunatic1/Glyph/issues) to see if someone has already reported it or requested it. If not, feel free to open a new issue using the provided templates!

## Setting up your development environment

To build and run Glyph Mobile locally:

1. Clone the repository: `git clone https://github.com/TheLunatic1/glyph-app.git`
2. Change directory: `cd glyph-app`
3. Install dependencies: `npm install`
4. Start development server: `npm start`
5. Run on attached Android device / emulator: `npm run android`
6. Run on iOS Simulator (macOS): `npm run ios`

## Pull Request Process

1. Ensure all code conforms to the codebase's glassmorphic styling and React Native best practices.
2. Verify that native Android (`android/app`) and iOS builds compile cleanly without warnings.
3. Update documentation and release notes with any interface or schema changes.
4. Submit your PR for review by the project maintainer (`TheLunatic1`).
